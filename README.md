## 🔐 算法详解

### 1. 凯撒密码 (1.py)
最经典的移位密码，将字母表中的每个字母按照固定数目 K=3 进行移位。加密时将小写字母映射到大写字母范围，解密时逆向操作。实现简洁，直观展示了替换密码的基本原理。

### 2. 维吉尼亚密码 (2.py)
维吉尼亚密码是一种多表代换密码，使用关键词 "hstc" 作为密钥。密钥循环重复以匹配明文长度，每个位置的字母根据密钥对应值进行不同偏移，比凯撒密码安全性更高。代码包含完整的加密与解密函数。

### 3. 哈希算法 (2.1.py)
演示 MD5 和 SHA1 两种哈希算法对同一消息的输出差异，并展示了输入中细微变化（添加空格）对哈希结果产生的巨大影响（雪崩效应）。

### 4. 希尔密码 (3.py)
基于线性代数的分组密码，使用 3×3 可逆矩阵作为密钥。明文按 3 个字母一组进行矩阵乘法加密，解密时使用密钥矩阵的模逆矩阵。代码完整实现了矩阵运算加密与解密流程。

### 5. DES 加密 (4.py)
使用 pyDes 库实现标准 DES 算法，ECB 模式，PKCS5 填充。密钥长度为 8 字节，输出通过 Base64 编码展示。演示了现代对称分组密码的标准工作模式。

### 6. AES 加密 (5.py)
使用 PyCryptodome 库实现 AES 算法，CFB 模式。密钥长度为 16 字节（128 位），使用随机初始化向量 IV。CFB 模式将 AES 转换为流密码，适合加密任意长度的数据。

### 7. RSA 加密 (6.py)
完整实现了 RSA 公钥密码系统：
- **扩展欧几里得算法**求乘法逆元
- **快速幂模运算**实现高效加密解密
- 参数：p=11, q=13, n=143, φ(n)=120, e=7, d=103
- 公钥 {7, 143}，私钥 {103, 143}

### 8. Arnold 猫脸变换 (Arnold_RGB.py)
对图像的 RGB 三个颜色通道分别应用 Arnold 变换进行像素位置置乱，n=8 次达到最佳加密效果，n=192 次可恢复原图。完整实现加密与解密过程，使用 matplotlib 可视化展示原图、加密图和解密图。

### 9. 数字水印 (watermark.py)
基于 LSB（最低有效位）的图片水印技术：
- 将载体图像低 2 位置零
- 将水印图像量化编码后嵌入
- 支持使用加密图片作为水印（二次实验）
- 通过相关系数（阈值 0.8）验证水印

### 10. 软件工程甘特图 (ruanjian.py)
使用 matplotlib 绘制的项目进度甘特图，包含需求分析、系统设计、前后端开发、数据分析、测试优化、交付总结等 7 个阶段，共计 16 周。
